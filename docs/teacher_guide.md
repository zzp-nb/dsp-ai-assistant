# DSP AI 智能教学助手 · 教师使用说明

> 这个页面用于课堂投影和学生课后学习。日常使用不需要安装软件，也不需要登录 GitHub。
>
> **默认是本地离线模式**：问答、公式推导和习题使用内置 DSP 知识库，不联网、不需要 DeepSeek API。只有部署负责人主动切换到在线模式时，才会调用 API。

## 一、先填好这三项

请部署负责人把下面信息填好，再交给任课教师：

```text
公网网址：____________________________________

班级访问密码：______________________________

教师管理密码：______________________________
```

- **班级密码**：发给学生，学生凭它进入学习空间。
- **教师密码**：只给任课教师，用于课堂问题管理、投影和额度设置。
- **不要把教师密码发给学生。**

建议把网址做成二维码放在课件最后一页，学生扫码进入。

---

## 二、上课前 10 分钟

1. 用教室电脑打开公网网址。
2. 如果页面显示“正在唤醒”或加载较慢，等待 30–60 秒，再刷新一次。
3. 点“教师入口”，输入教师密码。
4. 进入“教师管理 → API 与系统”，确认运行模式为“本地离线”。离线模式不需要测试 DeepSeek。
5. 检查“课程知识库”里的资料是否还在；内置知识库不受影响。
6. 打开“课堂大屏”，按 `F11` 全屏，切到投影仪。

> 免费云端应用长时间无人访问会休眠，第一次打开慢是正常现象。提前打开可以避免上课时等待。

---

## 三、第一次导入课程资料

1. 教师登录后进入“课程知识库”。
2. 点击“选择课程资料”，上传 PPT/PDF。
3. 点击“重建课程索引”，等待完成。
4. 查看“已导入资料”：
   - “已索引”表示可以使用
   - “图片页”表示这一页没有可提取文字，不会自动 OCR
5. 回到“智能问答”提一个课程问题，确认下方出现“查看课程资料依据”。

### 注意

- 图片、扫描页、公式截图不会自动识别；需要人工补录，入口在知识库页面。
- 没有上传资料时，回答来自内置 DSP 知识库；有资料时会同时引用原文。
- **不要把 PPT/PDF 上传到公开 GitHub**，只在本应用里上传。

---

## 四、课堂互动

1. 学生用手机打开同一个网址，输入班级密码。
2. 学生在“课堂互动”提交问题。
3. 问题**不会自动上屏**。
4. 教师在“教师管理 → 课堂问题”中：
   - 点“生成 AI 回答”
   - 选择“仅展示问题”或“展示问题 + AI”
   - 需要时点“关闭展示”
5. “课堂大屏”每 3 秒自动刷新。

教师可以控制是否向课堂展示 AI 回答。

---

## 五、使用统计与额度

离线模式不调用 API，因此没有 Token 费用，也不需要设置额度。教师端仍可查看学生课堂问题。

如果以后切换到在线 DeepSeek 模式，才需要在“调用额度设置”中设置：

- 每位学生每日调用上限
- 全班每日调用上限
- 单次输入字符上限
- 单次输出 Token 上限

建议在线模式下保留全班每日总量上限，避免 API 费用失控。

## 六、常见情况

| 现象 | 处理 |
|---|---|
| 页面打不开 | 等待 1 分钟刷新；确认公网网址没有输错 |
| 一直显示加载 | 刷新页面；免费云端冷启动可能需要 30–60 秒 |
| 提示 API 认证失败 | 只有在线模式会遇到；检查 DeepSeek Key，或切回离线模式 |
| 提示余额不足 | 只有在线模式会遇到；到 DeepSeek 控制台充值，或切回离线模式 |
| 问答没有教材依据 | 检查是否上传并索引资料；没有资料时使用内置知识库 |
| 上传资料不见了 | 免费云端重启可能清空文件，重新上传并建索引 |
| 学生打不开但教师能打开 | 换手机网络测试；学校网络可能限制该域名 |

## 七、重要提醒

1. **免费 Streamlit Cloud 不保证永久保存数据。** 休眠、重启或重新部署后，课程资料、课堂问题和统计数据可能丢失。教师电脑上要保留原始 PPT/PDF。
2. **离线模式没有 API 费用。** 如果部署负责人切换成在线模式，才会产生 DeepSeek 费用。
3. **不要把教师密码发给学生。**
4. **不要把 API Key 写进 PPT、截图、微信群或 GitHub。** 离线模式不需要 Key。
5. 如果部署负责人不再维护，教师应保留 GitHub、Streamlit 账号的登录权限，或提前完成账号交接。

---

## 八、需要长期稳定使用时

免费版适合课程演示和短期教学。如果要求：

- 一学期数据不丢
- 不因休眠而等待
- 课程资料永久保存

则需要使用带持久磁盘的付费部署，或由学校提供服务器。可让部署负责人按项目中的 `docs/deployment.md` 迁移。
