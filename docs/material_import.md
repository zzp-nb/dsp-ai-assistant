# 课程资料导入与解析说明

## 1. 支持的文件

| 格式 | 解析器 | 能保留 | 不能保证 |
|---|---|---|---|
| `.pdf` | PyMuPDF | 文本层、页码、PDF 目录章节 | 扫描页、公式图片、复杂排版 |
| `.pptx` | python-pptx | 文本框、表格、组合形状、讲稿备注、幻灯片号 | 图片/截图内文字、SmartArt 全部内容 |
| `.txt` / `.md` | 内置读取 | 全文、章节标题（按“第 X 章/节”识别） | 图片 |
| `*.ocr.txt` | 侧车补录 | 按页/幻灯片注入文字 | 不会自动 OCR |

不支持 `.ppt`、`.docx`、`.key`。旧版 PPT 请先另存为 `.pptx`。

## 2. 目录方式导入

把文件放进：

```text
data/course_materials/
```

支持多份 PDF、多份 PPTX，同级目录、不递归子目录。然后在教师端点击“重建课程索引”，或运行：

```bash
python scripts/build_index.py
```

## 3. 解析与检索规则

1. PDF 按页提取文本，页码从 1 开始，与 PDF 阅读器页码一致（不考虑印刷页码偏移）。
2. PPT 按幻灯片提取，幻灯片编号从 1 开始。
3. 每个文本块保留：资料名、页码/幻灯片号、章节、小节标题。
4. 检索时 **PPT 权重高于 PDF 教材**，补充文本介于两者之间。
5. 回答下方展示实际检索到的资料片段和位置，不由模型编造页码。
6. 若检索不到足够相关内容，页面会标明“未检索到直接资料 · AI 补充解释”。

## 4. 图片、公式图片、扫描页

### 系统会怎么做

- 解析时统计图片页/无文本页。
- 在资料表显示“图片页”数量。
- 在页面提示“未做 OCR”，不会假装内容已经进入索引。

### 人工补录

为原资料创建同名侧车文件：

```text
data/course_materials/第1章.pdf
data/course_materials/第1章.pdf.ocr.txt
```

或：

```text
data/course_materials/第2章.pptx
data/course_materials/第2章.pptx.ocr.txt
```

侧车内容格式：

```text
[[PAGE 12]]
这里是 PDF 第 12 页的图片/扫描内容转录。

[[PAGE 13]]
可以继续写多页。

[[SLIDE 7]]
这里是 PPT 第 7 张幻灯片的图片文字。
```

- PDF 用 `[[PAGE n]]`，PPT 用 `[[SLIDE n]]`；两种标记系统都能识别。
- 没有标记时，整段文本会作为第 1 页补充。
- 保存侧车后必须重新建立索引。
- 网页教师端也提供“图片 / 扫描页文字补录”上传入口。

### 为什么不做自动 OCR

- OCR 依赖额外模型/系统库，会显著增加 Streamlit Cloud 的依赖、内存与启动时间。
- 公式 OCR 的准确率不稳定，错误公式比“不识别”更危险。
- 第一版优先保证：**知道哪里没识别，并允许人工补录**，而不是假装完整。

如果后续需要 OCR，可以在 `core/document_loader.py` 的侧车机制之前增加 OCR provider，并把识别结果按页注入；页面和检索层无需重写。

## 5. 章节识别

- 优先使用 PDF 自带目录（outline）映射页码。
- 其次按正文中的“第X章”“第X节”“Chapter N”识别。
- PPT 按幻灯片文字和文件名推断。
- 章节不是强制元数据；识别不到时显示“未标注”，仍可检索。

## 6. 切块策略

- 默认每块最多约 700 字符，重叠约 80 字符。
- 优先在段落、句号、问号、分号处切分。
- 每个块保留来源页码，因此同一页可能产生多个块。
- 索引文件：

```text
data/vector_store/
├── chunks.jsonl
├── vectors.npz
├── bm25.json
└── manifest.json
```

## 7. 重建索引会发生什么

- 重新扫描 `data/course_materials/`。
- 重新解析全部资料。
- 覆盖旧索引文件。
- 更新数据库中的资料状态、页数、块数、图片页数量。
- 移除已从目录删除的资料记录。
- 索引构建失败时不会删除原始资料。

## 8. 检索技术说明

第一版使用：

- **BM25**：中文按字/二元/三元组 + 英文词切分，关键词相关性。
- **本地哈希 TF-IDF 向量**：无需下载模型、无需外部 Embedding API。
- 两者加权融合，并对 PPT 加轻微优先级。
- 相似度阈值、Top-K 可通过环境变量配置：

```dotenv
DSP_RETRIEVAL_TOP_K=5
DSP_MIN_RETRIEVAL_SCORE=0.12
```

不假设 DeepSeek 对话模型能生成 Embedding。未来可替换 `core/embedding.py` 的 `TextEmbedder` 接口。

## 9. 版权与隐私

- 课程资料目录已加入 `.gitignore`。
- 不要把教材 PDF、教师 PPT 上传到公开 GitHub。
- 云端部署时确认平台的数据使用条款。
- 课堂问题数据库包含学生问题，备份文件也应妥善保管。
